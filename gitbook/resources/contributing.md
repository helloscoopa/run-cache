# Contributing to RunCache

Contributions are welcome. The contributor guide lives in the repository, next to the code it describes:

- [CONTRIBUTING.md](https://github.com/helloscoopa/run-cache/blob/main/CONTRIBUTING.md): setup, the checks a pull request must pass, and how to write docs and code samples
- [CHANGELOG.md](https://github.com/helloscoopa/run-cache/blob/main/CHANGELOG.md): what changed in each release, and what is coming next
- [Issues](https://github.com/helloscoopa/run-cache/issues): bug reports and feature proposals

In short: open an issue before larger changes, add tests and a changelog entry with your change, and make sure `npm test`, `npm run lint`, `npm run build` and `npm run docs:check` pass.
