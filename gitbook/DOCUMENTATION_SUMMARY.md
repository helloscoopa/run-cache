# RunCache GitBook Documentation Summary

## Overview

This GitBook documentation provides comprehensive information about the RunCache library, a dependency-free, lightweight runtime caching library for JavaScript and TypeScript applications. The documentation is structured to be user-friendly and accessible for both beginners and advanced users.

## Documentation Contents

### Getting Started
- **Installation**: Instructions for installing RunCache in different environments
- **Quick Start**: Basic usage examples to get up and running quickly
- **Basic Usage**: Common patterns and fundamental concepts

### Core Features
- **Cache Management**: Basic cache operations (set, get, delete)
- **TTL and Expiration**: Working with time-to-live functionality
- **Automatic Refetching**: Setting up auto-refresh for cache entries
- **Source Functions**: Using functions to generate cache values
- **Eviction Policies**: LRU and LFU policies for managing cache size
- **Pattern Matching**: Using wildcards to work with groups of cache keys

### Advanced Features
- **Tag-based Invalidation**: Grouping and invalidating related cache entries
- **Dependency Tracking**: Creating relationships between cache entries
- **Event System**: Subscribing to cache events
- **Middleware**: Intercepting and transforming cache operations
- **Persistent Storage**: Saving cache data across application restarts
- **Resource Management**: Optimizing memory usage and cleanup

### API Reference
- **RunCache**: Complete API documentation for the main class
- **Storage Adapters**: Documentation for built-in storage adapters
- **Events**: Reference for all event types and handlers
- **Types**: TypeScript type definitions

### Guides
- **Best Practices**: Recommendations for effective cache usage
- **Performance Optimization**: Tips for maximizing performance
- **Debugging and Logging**: Troubleshooting and monitoring
- **Migration Guide**: Upgrading from previous versions

### Resources
- **FAQ**: Frequently asked questions
- **Contributing**: Guidelines for contributing to the project
- **License**: License information
